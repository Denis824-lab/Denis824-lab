## Что проверяю перед публикацией

- сборка (где она есть) и линтер проходят без ошибок;
- ссылки и изображения открываются;
- страницы работают на ширине 320–390 px;
- меню и диалоги доступны с клавиатуры, Escape закрывает окно;
- в текстах нет выдуманных данных и обещаний.
